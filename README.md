# 인왕제색도 3D

겸재 정선의 「인왕제색도」(1751)를 걸어서 오를 수 있는 1인칭 3D 산으로 만든 웹 게임입니다. three.js와 수묵 후처리 셰이더(먹 농담, 붓 윤곽선, 한지 결, 높이별 안개)로 그림의 질감을 살렸습니다.

**플레이:** https://usuu94152-collab.github.io/inwang-3d/

## 할 수 있는 것
- 비 갠 인왕산 산행: 수성동 계곡, 선바위, 꼭대기, 치마바위, 범바위
- 퀘스트: 노화가 대신 다섯 경치를 찾아 그림 완성하기(찾을 때마다 안개가 걷힘), 할머니의 약초
- 한양도성 성곽, 폭포, 숲속 기와집과 초가 마을
- 그림 해설 안내판 7개, 수첩(의뢰·등고선 지도·만난 사람·그림 이야기·스케치북)
- 스케치 모드, 진행 상황 자동 저장(브라우저 localStorage)

## 조작
| 키 | 동작 |
|---|---|
| W A S D / 방향키 | 걷기 (Shift 달리기) |
| 마우스 | 둘러보기 (클릭해서 고정) |
| E | 말 걸기 · 살펴보기 |
| J / Tab | 수첩 · 지도 |
| C | 스케치 |
| P | 수묵 효과 켜고 끄기 |
| M | 음악 |

휴대폰에서는 왼쪽 조이스틱으로 걷고, 화면 오른쪽을 끌어서 둘러봅니다. 산길(흙길)을 따라가면 가파른 곳도 오를 수 있고, 길을 벗어난 급한 바위는 오를 수 없습니다.

## 참고
산의 모양과 명소 위치는 실제 지형이 아니라 그림의 인상을 따라 다시 지었습니다. 단일 `index.html` 파일이며, 외부 의존성은 cdnjs의 three.js r128과 Google Fonts뿐입니다.
